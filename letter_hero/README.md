# Letter Hero (Primary 1)

Calm A–Z / a–z recognition for P1 EFL / SpLD students.

**Belongs in:** [Mangohk/teaching-games](https://github.com/Mangohk/teaching-games) under **Primary 1** (alphabet).

## Folder layout (teaching-games format)

```
letter_hero/
  index.html   # game
  index.jpg    # hub thumbnail
```

## Install into teaching-games

1. Copy this folder to the repo root: `teaching-games/letter_hero/`
2. In hub `index.html`, under **Primary 1**, add the card from `HUB_CARD.html`
3. Update the hub stamp (Hong Kong time), e.g.  
   `<p class="hub-updated">Updated 23 Oct 2026, 12:15</p>`

## Play modes

| Mode | Action |
|------|--------|
| Find It | See a letter → tap the match |
| Match Friends | Match uppercase ↔ lowercase |
| Hear & Tap | Listen → tap the letter |
| Surprise Mix | Random mix of the three |

Case options: **ABC** / **abc** / **Aa Bb**. Ten rounds, stars for first-try correct; wrong answers = “Try again” (no timer).
