# spelling-challenge · Version Two

**拼字勇者** — a simple linear spelling RPG for kids.

Open `index.html` to play (or visit the GitHub Pages site).

## How to play

1. Tap **開始冒險** — the hero walks forward.
2. Meet a **word monster**. The Chinese meaning is shown; spell the English word in the blanks.
3. **Correct spelling** damages the monster. **Wrong spelling** damages the hero.
4. Defeat a monster to get **equipment** (ATK, DEF, or special effects).
5. A **Boss** appears around the middle of the word list.
6. Clear all words to win, or Game Over if hero HP reaches 0.

## Word list (for now)

The first adventure uses a fixed dictation sample (school facilities). A settings screen to edit words will come later.

## Assets

Illustrations live in `assets/` (hero, monster, boss, scene, equipment).
