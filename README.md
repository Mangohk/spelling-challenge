# spelling-challenge · Version Two

**拼字勇者** — a simple linear spelling RPG for kids.

Open `index.html` to play (or visit the GitHub Pages site).

## How to play

1. Tap **開始冒險** — the hero walks forward.
2. Meet one of **20 named monsters** (each with its own art).
3. Each attack draws a **spelling word** from the dictation list (can differ every hit). The hint is shown as a **picture**; spell the English word in the blanks.
4. **Correct spelling** damages the monster. **Wrong spelling** damages the hero.
5. Defeat a monster to get **equipment** (ATK, DEF, or special effects).
6. Bosses: **書卷巨龍** (mid) and **暗影帝王** (final).
7. Clear all 20 monsters to win, or Game Over if hero HP reaches 0.

## Word list (for now)

Spelling prompts use a fixed dictation sample (school facilities). Monster names are separate. A settings screen to edit words will come later.

## Assets

- `assets/` — hero, scene, equipment
- `assets/monsters/` — 20 monster portraits (`m01` … `m20`)
- `assets/hints/` — picture hints for each spelling word
